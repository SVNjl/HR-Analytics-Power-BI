Spearheaded the development of a robust HR Analytics Dashboard, driving strategic insights to enhance employee performance and retention for organizations.

Methodology :-
1. Data Extraction : Managed dataset provided in .csv format.
2. Data Cleaning : Employed Power BI to eliminate nulls, errors and duplicates, ensuring data integrity. Then the transformed data loaded into report view for in-depth analysis.
3. Data Implementation : Utilized DAX to create calculated measure (AttritionRate) and column (AttritionCount) for advanced analysis.
4. Data Visualization : Leveraged customized visualizations to uncover intricate data relationships, empowering user-driven insights.
